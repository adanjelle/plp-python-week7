
# Python Lists Assignment

This assignment demonstrates Python list operations, loops, conditional statements, and list reporting.

## Files

- **list_warmup.py** – Demonstrates creating a list, accessing items using indexes, appending, removing, and counting items.
- **shopping_list.py** – Implements an interactive shopping list manager using loops and conditional statements.
- **list_report.py** – Generates a numbered list, counts item names with more than four letters, and identifies the longest item name.

## What I Learned

- How to create and manipulate Python lists.
- How to use loops, conditions, and user input.
- How to count, compare, and report information from lists.
